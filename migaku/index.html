2. 取得・利用する情報

本アプリにはアカウント登録の仕組みも広告もありません。氏名・メールアドレス・連絡先・位置情報・広告ID は取得しません。写真ライブラリ・カメラ・マイクも使いません。

データ目的保存場所
遊びの記録（落とした汚れ・おだちん・買った道具や強化・磨いた場所・見つけもの・設定）続きから遊ぶため端末内のみ
使い方の統計（3. のとおり）アプリの改善のためPostHog のサーバー（米国）
年末の大掃除パスの購入の記録（4. のとおり）購入の確認と売上の集計のためApple、RevenueCat のサーバー（米国）

  • 遊びの記録は端末内のアプリ専用の領域に保存し、iCloud には同期しません。アプリを削除すると、遊びの記録も削除されます。端末のバックアップ（iCloud バックアップなど）の設定によっては、そのバックアップに含まれます。

3. 使い方の統計（PostHog）

遊びのどこで止まるか、どこが長すぎるかを知ってアプリを直すため、遊びの節目を分析サービス PostHog（運営会社: PostHog Inc.）へ送ります。

  • 始め方と止め方: 最初の場所を磨ききったあとに、統計を送るかどうかを1回だけお尋ねします。答えるまでは、節目を端末の中に30件まで溜めるだけで送りません。「送る」を選ぶと溜めた分と以後の分を送り、「送らない」を選ぶと溜めた分を捨てて何も送りません。あとから、設定の「使い方の統計を送る」でいつでも切り替えられます。
  • 送る節目（11種類）: 起動した、遊び始めた、最初の強化を買った、「自動で空ける」を買った、道具を買った、場所を磨ききった、地図で場所を選んだ、51か所を磨ききった、次の周を始めた、離れていて戻った、統計をオフにした。
  • 節目に付ける値: 何か所目か、場所や道具や強化の種類（英数字の記号）、遊んだ秒数、何周目か、離れていた時間の区分（1分・5分・15分…のような段）、離れていた時間が上限に達したか。ほかに、アプリの版番号、節目の日時、端末の中で作ったランダムな ID を付けます。
  • ランダムな ID: 同じ端末の節目をまとめるために、アプリを入れたときに端末の中で作る番号です。端末や利用者個人とは結び付かず、アプリを削除すると失われます。
  • 送らないもの: 氏名・メールアドレス・位置情報・広告ID・端末の製造番号・入力した文字。通信元の IP アドレスから所在地を推定する機能と、人ごとのプロフィールを作る機能は、送るたびに無効の指定を付けています。
  • 使い道: アプリの改善だけに使います。広告や、ほかの会社のデータとの組み合わせには使いません。トラッキング（他社のアプリやサイトをまたいだ追跡）はしません。
  • 送信先の所在地: 米国（PostHog の米国のサーバー）。

4. アプリ内課金（年末の大掃除パス）

  • 購入の手続きと支払いは Apple の App Store が行います。カード番号などの支払いの情報を、運営者が受け取ることはありません。
  • パスを持っているかは、起動のたびに端末の App Store の購入の記録から読みます。遊びの記録には書きません。
  • 売上を集計するため、購入の記録（商品・価格・通貨・購入日時・取引の番号・国や地域）を、購入の管理サービス RevenueCat（運営会社: RevenueCat, Inc.、米国）へ送ります。購入したときのほか、起動したときにも、購入の記録をそろえるために RevenueCat と通信します。RevenueCat には、RevenueCat が端末ごとに作る匿名の ID が付きます。氏名・メールアドレスは送りません。
  • RevenueCat に送った購入の記録は、使い方の統計（3.）とは結び付けません。

5. 外部への提供

3. の PostHog と 4. の RevenueCat のほか、利用者の情報を第三者に提供・販売することはありません。法令に基づく開示の求めがあった場合を除きます。

6. 端末の機能

位置情報・カメラ・写真・連絡先・マイクの権限は使いません。通知も使いません。端末の振動と音は遊びの手ごたえのために使い、設定で止められます。

7. 写真の権利

アプリに載せる風景の写真は、Wikimedia Commons で CC0・パブリックドメイン・CC BY として配布されているものを、切り抜きと縮小をして使っています。作者・題・ライセンスは、アプリの設定の「写真の出典」に載せています。

8. データの削除

アプリを削除すると、端末内の遊びの記録とランダムな ID は削除されます。PostHog に送った統計は、利用者と結び付く情報を含まないため、個別に探して削除することはできません。購入の記録は Apple アカウントに残り、アプリを削除しても消えません（購入の復元のため）。以後の送信は、設定の「使い方の統計を送る」をオフにすると止まります。

9. 子どものプライバシー

本アプリは特定の年齢層を対象に個人情報を集める設計ではなく、13歳未満の方の個人を特定する情報も取得しません。

10. 改定

本ポリシーは予告なく改定されることがあります。重要な変更は、アプリ内またはストアの掲載ページでお知らせします。

利用規約

1. サービスの内容

本アプリは、指でこすって汚れを落とし、下から日本の実写の風景が現れる放置型のゲームです。アプリ内の「おだちん」は遊びの中だけで使う数値で、現金や電子マネーと交換できず、お金で買うこともできません。表示される所要時間・重さ・残りなどの数値はゲームの演出で、実際の清掃や物の重さを表すものではありません。

2. 広告・保存

本アプリには広告を表示しません。遊びの記録は端末内に自動で保存します。端末の故障・機種変更・アプリの削除、またはお使いの OS の不具合による記録の消失について、運営者は復元をお約束できません。

3. アプリ内課金

  • 序章と47都道府県のすべてを、無料で最後まで遊べます。
  • 有料の「年末の大掃除パス」（1回払いの買い切り）を購入すると、次の2つが使えます。
    • 年末の大掃除: 47都道府県を磨き終えたあと、51か所を最初からもう一度磨けます。おだちん・道具・強化・磨いた場所は最初からになり、汚れは周を重ねるごとに落ちにくくなります。そのかわり、おだちんは一周ごとに3倍入ります。カードと見つけものは残ります
    • アプリを閉じているあいだに数える上限が、12時間延びます
  • 価格は App Store の購入画面に表示する金額です。支払いは Apple が行います。返金は Apple の定める手続き（https://reportaproblem.apple.com）によります。
  • 購入は Apple アカウントに記録されます。機種変更やアプリの入れ直しのあとは、アプリの設定の「購入を復元」で使えるようになります。「最初からやり直す」で遊びの記録を消しても、パスは消えません。
  • 「おだちん」は、パスを含めてお金で買うことはできません。

4. 利用状況の計測

使い方の統計を送るのに、外部のサービス（PostHog）を使います。送るかどうかは初回にお尋ねし、設定でいつでも止められます。送る内容は、プライバシーポリシーのとおりです。

5. 写真・権利

  • アプリに載せる風景の写真は、Wikimedia Commons で CC0・パブリックドメイン・CC BY として配布されているものを、切り抜きと縮小をして使っています。作者・題・ライセンスはアプリの設定の「写真の出典」に載せています。CC BY の写真の権利は各作者にあります
  • アプリの画面、音、文章、プログラムの権利は運営者にあります。個人で楽しむ範囲を超えた複製・配布・販売はできません
  • 風景の写真に写る建物・場所は実在のものです。掃除をする場面は、実際の場所を汚す・損なうことを勧めるものではありません

6. 禁止事項

  • アプリの解析・改変（リバースエンジニアリング）、不正な手段で遊びの記録を書き換えること
  • 法令や公序良俗に反する使い方、運営者や第三者に損害を与える使い方
