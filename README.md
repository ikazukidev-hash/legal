# legal

GitHub Pagesがmainブランチから配信するレガシーな素のHTMLビルドで、ビルド手順やフレームワークは無い: https://ikazukidev-hash.github.io/legal/
アプリを追加するときは、既存アプリのディレクトリ（例: dekitabi/）をコピーし、`index.html`の構成（タイトル・プライバシーポリシー→利用規約の順・見出しの型）を保ったまま、アプリ名・課金内容・連絡先だけを書き換える。ルートの`index.html`と`support/index.html`にもリンクとアプリ名を追記する。
変更はmainへのpush後、リポジトリ所有者本人の操作でGitHub Pagesに反映される。
