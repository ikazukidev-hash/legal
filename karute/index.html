プライバシーポリシー

制定日: 2026-09-13
対象アプリ: カルテ帳（サロン・施術所のための顧客カルテと予約帳）

「カルテ帳」（以下「本アプリ」）は、KAZUKI SAWASHIMA（以下「開発者」）が提供する、1〜3人で営むサロン・施術所向けの顧客カルテ・予約帳・売上記録のアプリです。本ポリシーは、本アプリで扱う情報の取り扱いを説明します。

アカウント登録がありません

本アプリには会員登録・ログインの仕組みがありません。開発者は、本アプリの利用者（店主の方）について、氏名・メールアドレス・電話番号・パスワード・生年月日・住所・支払い情報のいずれも取得しません。次項の「2台目にも同じものを出す」を始めた場合にサーバー側に作られるのは、サーバーが自動で振った文字列のアカウント識別子だけで、それが誰のものであるかを開発者が知る手段はありません。

広告・分析・トラッキング

本アプリは広告を表示しません。広告SDK・行動分析SDKを組み込んでいません。利用状況の計測（アナリティクス）も行いません。App Store が定める意味での「トラッキング」を行わず、広告識別子（IDFA）を取得しません。他社への情報提供・販売も行いません。

端末の中だけに残るもの（既定の状態）

本アプリに入力した内容は、既定では端末内のアプリ専用領域にのみ保存されます。次項の操作を行うまで、記録が端末の外へ出ることは一切ありません。アプリを削除すると、端末内のこれらのデータも削除されます。

「2台目にも同じものを出す」を始めたとき

本アプリには、同じお店の端末2台で同じ帳面を見るための機能があります。この機能は既定では動いておらず、設定画面の「2台目にも同じものを出す」で利用者が「始める」を押したときにだけ開始されます。開始すると、以後に書いたものの写しが、開発者が管理するサーバー（Cloudflare Workers / D1・保存先の地域は Cloudflare の割り当てによります）へ送られます。

サーバーへ送られるもの（お店が記録した内容そのものです。お客さまの個人情報が含まれます）

お客氏名・ふりがな・電話番号・おぼえがき・非表示にしたかどうか
カルテ店主が定義した項目の名前・種別・並び順と、そこに書いた値
来店の記録日時・メニュー・金額・担当・ひとこと
予約日時・所要・担当・メニュー・覚書・呼び名
スタッフ名前・色・並び順

サーバーへ送られないもの

  • 施術写真。写真は端末の中だけに残ります。送信の直前に写真の項目を空にしてから送るため、2台目に写真が出ることはありません
  • 30日前まで戻すための控え。控えは端末ごとに別々で、端末の外へ出ません
  • 店主の氏名・メールアドレス・電話番号・パスワード（そもそも取得しません）
  • 端末の識別子（IDFA・広告ID・プッシュ通知トークン）、位置情報、連絡先、写真ライブラリ、カレンダー、操作の履歴

通信はすべて HTTPS で行われます。2台をつなぐ「合言葉」（6字）と、端末がサーバーに示す合鍵は、サーバー側では SHA-256 のハッシュだけを保存し、元の文字列を保存しません。ただし、預かった記録そのものは、端末側で暗号化してから預ける形（開発者が中身を読めない形）にはしていません。保存領域の暗号化は Cloudflare の設定に従います。この点を正確にお伝えしたうえで、次の運用を守ります。開発者は、障害の調査に必要な場合を除き、預かった記録の中身を閲覧しません。法令に基づく開示請求があった場合を除き、第三者へ提供しません。

お客さまの個人情報について（店主の方へ）

本アプリに入力されるお客さまの氏名・電話番号・カルテの内容は、お店（店主）がご自身の判断で取得・記録される個人情報です。個人情報の取り扱いについての説明・同意の取得は、お店とお客さまとの間で行っていただく必要があります。開発者は、上記「2台目にも同じものを出す」を利用された範囲で、その保管をお店から委託されて行う立場となり、預かった情報をお店のためにのみ用います。

預かる期間

サーバーに預けたものは、そのアカウントの端末が1台でも残っている間、保管されます。最後の1台が抜けた時点で、アカウントと、そこに預けられた記録は、すべてサーバーから削除されます。期限で自動的に消える仕組みは設けていません（お店が使い続けている間に記録が消えないことを優先しているためです）。

全部を消す方法

  1. 残しておきたい場合は、先に〈設定〉→〈全部書き出す〉、または〈売上〉画面の「書き出す」で、記録をファイルに書き出してください（表計算で開ける形式です）
  2. 2台でお使いの場合は、2台目の〈設定〉→〈2台目にも同じものを出す〉→〈この端末を外す〉を実行します
  3. 続けて1台目で同じ操作（〈この端末を外す〉）を実行します。最後の1台が抜けた時点で、サーバー上のアカウントと預けた記録がすべて削除されます
  4. 端末の中の記録も消す場合は、iPhone のホーム画面から本アプリを削除してください。アプリ専用領域に保存された記録と、30日ぶんの控えも一緒に削除されます

操作ができない事情があるときは、下記の連絡先へご連絡ください。開発者側で削除の手続きを行います。アカウントを特定するための情報は端末の中にしかないため、その場合はお使いの端末で〈設定〉→〈2台目にも同じものを出す〉に表示されている状態をお知らせください。

書き出しについて

〈全部書き出す〉で作ったファイルは、端末の一時領域に書き出したうえで、iOS の共有画面を通じて利用者ご自身が送り先（メール・ファイル・AirDrop など）を選びます。開発者がこのファイルを受け取ることはありません。

お子さま向けではありません

本アプリは事業者向けの業務用アプリで、13歳未満の方を対象としていません。

ポリシーの変更について

本ポリシーは、法令の変更や本アプリの機能追加に伴い変更されることがあります。預かる情報の種類が増えるなどの重要な変更を行う場合は、本ページを更新し、アプリ内でもお知らせします。

利用規約

制定日: 2026-09-13

サービスの内容

本アプリは、お店が記録した顧客カルテ・予約・来店・売上を、端末内に保存し、必要に応じて2台の端末で同じ内容を見られるようにするアプリです。表示される集計（来店回数・合計・1回あたりの金額など）は、利用者が入力した内容にもとづくもので、開発者はその正確性を保証しません。

本アプリは医療機器ではなく、診断・治療・施術の効果について何かを述べるものではありません。カルテの項目名・内容は、すべて利用者ご自身が決めて入力するものです。

2台までの同期について

  • 1つのアカウントにつなげる端末は2台までです
  • 2台をつなぐ合言葉は6字で、発行から10分間・1回だけ有効です
  • 同じ内容を2台で同時に書き換えた場合は、サーバーに後から届いたほうが残ります
  • 電波が届かない間も記録は端末に残り、つながったときに送られます
  • サーバーは無償で提供される付随機能であり、24時間の稼働・特定の応答速度を保証するものではありません。停止・仕様変更を行う場合は、本ページとアプリ内でお知らせします

料金について

本アプリは、現時点でアプリ内課金を提供していません。今後、有料のプランを追加する場合は、価格・期間・自動更新の有無と解約の方法を、購入の前に購入画面と本ページへ明示します。

禁止事項

本アプリを、法令に反する目的、他人になりすます目的、サーバーに過大な負荷をかける目的（自動化された大量の要求、合言葉の総当たりを含みます）で利用することはできません。

免責

本アプリの利用により生じた損害について、開発者は故意または重大な過失がある場合を除き責任を負いません。端末の故障・紛失・機種変更・アプリの削除によるデータの消失に備え、〈全部書き出す〉によるファイルの保存を定期的に行ってください。

規約の変更

本規約は変更されることがあります。変更後の規約は本ページに掲示した時点で効力を生じます。
