運営者と対象

KAZUKI SAWASHIMA（以下「開発者」）は、iPhoneアプリ「段取り日和」（以下「本アプリ」）で扱う情報について、次のとおり説明します。

段取り・予定の保存

入力した段取り名・作業名・所要時間、予定名・日時・固定や完了の状態は、このiPhoneのアプリ専用領域に保存します。通知やカレンダー表示の設定も端末に保存します。アカウント登録はありません。

段取りや予定の内容、参照した端末カレンダーの予定を、開発者やRevenueCatのサーバー、分析サービスへ送信する機能はありません。広告は表示しません。使い方の統計と購入に関する情報の取り扱いは、次の項目で説明します。

使い方の統計

本アプリはアプリの改善のために、使い方の統計を送ります。送るのは、操作の名前（例: 段取りを保存した、予定を完了にした、PROの案内を開いた）、その操作にともなう種類・数・結果、操作の日時、アプリの版番号、端末の中で作ったランダムなIDです。このIDは端末ごとに作るもので、アプリを削除すると消えます。

段取りや予定の名前・内容、カレンダーの予定、氏名・メールアドレスは送りません。広告識別子（IDFA）は使わず、ほかの会社のデータと結び付けることもしません。

送信先は分析サービスのPostHog（PostHog, Inc.・米国）と、開発者が運営する集計用サーバー（m.kurabedoki.com）です。PostHogへの送信では、通信元のIPアドレスから所在地を推定する機能を、本アプリから止めています。集計用サーバーにはアプリ名・出来事の名前・版番号だけを送り、IPアドレスは保存せず、日ごとの件数だけを残します。

初めて起動したときに、使い方の統計を送ることをお知らせします。「送らない」を選ぶか、設定の「使い方の統計を送る」をオフにすると、それ以降は何も送りません（設定でオフにしたときだけ、止めたことを示す1件を止める直前に送ります）。止めても使える機能は変わりません。

購入情報とRevenueCat

PROの購入状態の確認と復元、不正な購入の防止、購入件数や売上の集計に、RevenueCat, Inc.のサービスを使います。アプリの起動時から通信するため、PROを購入していない場合も情報が送られます。

RevenueCatへ送られる情報には、自動生成されるアプリ利用者ID、取得可能な端末識別子IDFV、端末の種類、OS・アプリ・SDKのバージョン、地域や通貨に関する設定などがあります。購入や復元では、商品の識別子、購入日時、取引やレシートに関する情報、購入状態を扱います。iOSのトラッキング許可の現在の状態も送信しますが、アプリからその許可を求める機能はありません。

氏名・メールアドレスや段取り・予定の内容をRevenueCatの顧客属性として設定する機能はありません。クレジットカード番号などの支払情報はAppleが扱い、開発者やRevenueCatは受け取りません。広告の表示や、広告目的で他社のアプリやサイトをまたぐ追跡は行いません。

RevenueCatは購入関連情報を処理するため、米国のAWSデータセンターを利用しています。保存期間を含むRevenueCatでの取り扱いは、RevenueCatのプライバシーポリシーに従います。

端末カレンダーの参照

端末カレンダーの表示を有効にするときに、iOSのカレンダーへのフルアクセスを求めます。許可後はカレンダー名と提供元、選択したカレンダーの予定名・日時・終日や空き時間の状態を、表示と重なりの確認に使います。自分が辞退した予定を除くため、参加者の自分に関する参加状態も参照します。元のカレンダーの予定を作成・変更・削除する処理はありません。

参照した予定の内容は表示中に扱い、アプリの保存ファイルや書き出すバックアップには含めません。選択したカレンダーの識別子は設定として端末に保存します。アプリの設定で表示を停止でき、iOSの設定からアクセス許可を取り消せます。

通知

通知を有効にした場合、開始時刻などの通知をiPhone内で予約します。通知には予定名を載せません。アプリの設定で通知を無効にすると、予約中の通知を取り消します。iOSの設定でも通知の許可を変更できます。

バックアップと復元前の控え

バックアップを書き出すと、保存したすべての段取り・予定と作成日時をJSONファイルにまとめ、選んだ保存先へ保存します。iCloud Driveなど端末外の保存先を選ぶ場合は、そのサービスの取り扱いも適用されます。通知やカレンダー表示の設定は含みません。バックアップには独自の暗号化やパスワードを付けていないため、共有先と保存先をご確認ください。

復元の直前には、現在の保存ファイルをアプリ内に控えとして残し、通常は最新3件を保管します。古い控えの整理に失敗した場合は、追加の控えが残ることがあります。また、端末の設定によってはアプリの情報がiCloudなどの端末バックアップに含まれます。本アプリによる端末間の自動同期はありません。

削除と残るコピー

段取りや予定はアプリ内で個別に削除できます。段取りを削除しても、その段取りから日付を指定して配置した予定は残ります。直前の操作を取り消すための一時データや、過去の復元前の控えに、削除前の内容が残る場合があります。

iPhoneからアプリ自体を削除すると、アプリ専用領域の記録と控えも削除されます。書き出したファイルや端末バックアップは、この操作では消えないため、それぞれの保存先で管理してください。

アプリを削除しても、AppleやRevenueCatが保管する購入関連情報は自動では削除されません。RevenueCatに保管された購入関連情報の削除を希望する場合は、「このアプリについて」の画面に表示される問い合わせIDを添えて、下記の窓口へご連絡ください。開発者がRevenueCatの管理画面でそのIDの記録を削除し、結果をメールでお知らせします。

問い合わせIDは記録を探すための手掛かりで、本人確認の手段ではありません。削除しても、PROの購入はApple Accountに残ります。削除のあとに本アプリを使い続けると、購入状態の確認のために記録が新しく作られることがあります。購入情報の削除と、Appleへの返金申請は別の手続きです。

お問い合わせと変更

お問い合わせでお送りいただいたメールアドレス・本文・問い合わせIDは、回答と不具合の調査、同じ件での追加のお問い合わせへの対応に使います。購入に関するお問い合わせでは、IDを使ってRevenueCatの購入関連記録を確認するため、メールの送信者とその記録が結び付きます。お問い合わせのメールの削除を希望する場合も、下記の窓口へお知らせください。

問い合わせIDは「このアプリについて」の画面で確認でき、共有先はご自身で選べます。予定やバックアップを自動送信することはありません。

情報の扱いが変わる場合は、このポリシーを更新します。

本アプリの利用には、Appleの標準使用許諾契約（Licensed Application End User License Agreement）が適用されます。PROについては次のとおりです。

PRO（月額）について

  • 無料では、段取りを2件まで保存できます。PROを購入すると、保存できる段取りの件数の制限がなくなります
  • 予定の作成・編集・まとめて動かす操作、保存した段取りの編集と利用、端末カレンダーの参照、通知、バックアップの書き出しと読み込みは、無料で使えます
  • PRO（月額）は自動更新のサブスクリプションです。価格と期間はApp Storeの購入画面の表示に従い、1か月ごとに自動で更新されます
  • 更新日の24時間前までに解約しない限り、サブスクリプションは自動で更新され、Apple Accountに請求されます。解約は「設定」>「Apple ID」>「サブスクリプション」から行えます
  • 以前に販売した買い切りのPROを購入済みの方は、引き続きPROを利用できます
  • 購入の権利はApple Accountに結びつき、同じApple Accountの端末では、購入画面の「購入を復元する」で復元できます
  • 返金はAppleの規約と手続きに従います。開発者は返金の可否を判断できません
