対象アプリ: ぺたしおり（旅のしおりを作り、行き先ごとの写真をスタンプにして、1枚の画像などで送るアプリ）

プライバシーポリシー

「ぺたしおり」（以下「本アプリ」）は、KAZUKI SAWASHIMA（以下「開発者」）が提供する、旅のしおりを作り、行き先ごとの写真をスタンプにして、1枚の画像などで送るアプリです。会員登録はありません。旅の名前・行き先・日付・メモ・写真は開発者のサーバーへ送りません。外部へ送る情報は以下に記載したものだけです。

iPhone に保存する情報

旅の名前・日付・行き先の名前と時刻・メモ、撮った写真と選んだ写真、写真から作ったスタンプ、選んだテンプレート、購入の状況は、iPhone の中の、このアプリだけが使う場所に保存します。アプリを削除すると消えます。

カメラと写真

  • カメラは行き先ごとの写真を撮ってスタンプにするためだけに使います。位置情報は使いません
  • 写真アプリからは、利用者が選んだ写真だけを読み込みます
  • 送る画像や写真を写真アプリに保存するときだけ、保存の許可を尋ねます。写真アプリの中の写真を、本アプリが読み取ることはありません
  • 「写真をまとめて」で送る写真からは、位置情報を取り除きます。取り除けない写真があるときは、その枚数をお知らせします。その写真を除いて送れます

画像・PDF・QRコードで送るとき

しおりの画像、冊子の PDF、QRコードのページ、写真は、iPhone の中で作ります。送り先は、利用者が共有の画面で選んだアプリや相手だけです。

  • QRコード（と、そこに入る URL）には、旅の名前・日付・行き先の名前・時刻・メモが入ります。写真は入りません
  • これらは URL の「#」より後ろに入り、開いたページ（https://ikazukidev-hash.github.io/legal/tabishiori/s）のサーバーには送られません。ページは GitHub Pages で配信されており、ページを開いたことを示すアクセスの記録が GitHub に残ることがあります
  • URL を LINE などのアプリで送ると、URL の全体が、そのやり取りの中に残ります。送り先にはご注意ください

ウィジェット

ウィジェットを使うと、旅行中の次の行き先と残りの数を表示します。アプリとウィジェットは、旅の名前・日付・行き先の名前と数・時刻・スタンプの絵を iPhone の中で受け渡します。この情報は iPhone の外へは出ません。

使い方の統計について

使いにくいところを見つけて直すため、使い方の統計を分析サービス PostHog（us.i.posthog.com）へ送信します。このうち、アプリを開いたことと、購入画面を開いたことの2つだけは、開発者が運営する集計用サーバー（m.kurabedoki.com）にも送信します。送信は初期設定でオンです。初回に知らせを表示し、設定画面の「使い方の統計を送る」をオフにすると、以後は送信しません。オフにしても、使える機能は変わりません。

  • 送る内容: アプリ名、操作の名前（アプリを開いた、旅を作った、行き先を足した、スタンプを押した、画像・PDF・QRコード・写真を送った、購入画面を開いた、購入した・復元した、使い方の統計をオフにした）、旅の日数・スタンプの作り方・送り方の種類・購入の種類などの小さな数や記号、アプリの版番号、日時、この iPhone の中で作ったランダムなID。集計用サーバー（m.kurabedoki.com）へ送るのは、アプリ名、操作の名前、アプリの版番号の3つだけです
  • 送らない内容: 旅の名前、行き先、日付、メモ、写真、氏名、メールアドレス、広告識別子（IDFA）、位置情報

ランダムなIDは同じ iPhone からの操作をまとめて数えるためだけに使い、ほかのアプリや他社のデータと照らし合わせません。広告の効果測定（App Tracking Transparency・IDFA・SKAdNetwork）は使いません。通信の仕組み上、送信元のIPアドレスは送信先（PostHog と集計用サーバー）に届きます。PostHog では、IPアドレスから所在地を推定する機能を本アプリ側から無効にしています。開発者の iPhone とTestFlightからは送信しません。

購入に関する情報

プレミアムとテンプレートは App Store のアプリ内課金（買い切り）を利用します。Apple が支払いを処理し、開発者はクレジットカード番号を取得しません。購入の確認は Apple の StoreKit で iPhone の中で行います。購入状況の把握には RevenueCat を利用し、購入の記録、RevenueCat が割り当てる匿名のユーザーID、購入した商品などを処理します。旅の中身（行き先・日付・メモ・写真・スタンプ）は RevenueCat へ送りません。

お問い合わせで受け取る情報

メールでお問い合わせいただいた場合は、返信先のメールアドレスと本文を、対応に利用します。

利用規約

サービスの内容

本アプリは旅のしおりを作り、行き先ごとの写真をスタンプにして、画像・PDF・QRコードなどで送るためのアプリです。行き先の名前・時刻は利用者が入力したもので、地図や観光の情報を提供するものではありません。

プレミアムとテンプレート（買い切り）

  • 名称: プレミアム（すべてのテンプレート）、テンプレートひとつ（各テンプレート）。月額・年額の課金はありません
  • 内容: プレミアムは、すべてのテンプレートが使えます。テンプレートひとつは、その1種類が使えます。切手シートとスタンプ帳は、購入しなくても使えます
  • 価格: アプリ内の購入画面に表示されます
  • 一度だけ払うもので、更新はありません。買った内容は購入画面の「復元」で、同じ Apple アカウントの iPhone に戻せます
  • 返金はAppleの規定に従います

免責

本アプリの利用により生じた損害について、開発者は故意または重大な過失がある場合を除き責任を負いません。旅の中身は iPhone の中にだけあるため、iPhone の故障や紛失、アプリの削除で失われることがあります。QRコードや URL で送った内容は、送った相手に表示され、相手がさらに転送することがあります。

規約の変更

本規約は予告なく変更されることがあります。変更後の規約は本ページに掲示した時点で効力を生じます。
